# CS 330: Computer Graphics and Visualization

## Project Overview

For my CS 330 final project, I created a 3D study desk scene using C++ and OpenGL. My scene includes a wooden desk, laptop, book, coffee mug, notebook, and pen. I used basic 3D shapes, textures, lighting, and camera controls to create an interactive 3D environment.

## How Do I Approach Designing Software?

This project helped me learn how to design a 3D scene using simple shapes. I started by selecting a reference picture and identifying the objects I wanted to create. I then chose basic shapes, such as boxes, cylinders, a plane, and a cone, to build the scene. Breaking the project into smaller parts made it easier to organize my work. I can use this approach in future software projects by planning the design before writing the code.

## How Do I Approach Developing Programs?

Throughout this course, I developed my 3D scene step by step. Each milestone helped me practice different skills, including transformations, textures, lighting, and camera navigation. I tested my code after making changes to check that everything worked correctly. One of my biggest challenges was lighting because some objects appeared too dark. I tried different settings and learned how important testing and debugging are when developing programs. This experience helped me become more comfortable using C++ and OpenGL.

## How Can Computer Science Help Me Reach My Goals?

Computer science helps me build the programming and problem-solving skills needed for my future career. Before this course, I had little experience creating 3D graphics. Learning OpenGL helped me understand how video games and other applications display and control 3D objects. Since I am interested in software development, mobile applications, and video games, I believe these skills will be useful in future courses and projects. I can also apply what I learned to create more interactive applications.
